# Midas 💰

**Midas** — это интерактивное веб-приложение для анализа, прогнозирования и оптимизации инвестиционного портфеля. Проект использует библиотеку `Prophet` для предсказания стоимости акций и рассчитывает оптимальное распределение весов активов для максимизации доходности или минимизации рисков.

---

## ✨ Основные возможности

* **Прогнозирование цен:** Обучение моделей `Prophet` на исторических данных для предсказания стоимости тикеров (например, `AMZN`).
* **Оптимизация портфеля:** Расчет рекомендуемых долей акций в портфеле на основе ожидаемой доходности.
* **Интерактивный UI:** Удобный веб-интерфейс на `Streamlit` с таблицами результатов и круговыми диаграммами `Plotly` для визуализации долей.
* **Сохранение результатов:** Автоматическая генерация графиков прогнозов в формате PNG и экспорт отчетов.

---

## 🛠 Стек технологий

* **Язык программирования:** Python 3.12
* **Интерфейс:** Streamlit, Plotly
* **Прогнозирование и математика:** Prophet, Pandas, NumPy
* **Управление проектом:** Poetry

## 🚀 Быстрый старт

### Требования
Убедитесь, что у вас установлен **Python 3.12** и менеджер пакетов **Poetry**.

### Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd Midas
   ```

2. Установите все зависимости через Poetry:
   ```bash
   poetry install
   ```

3. Активируйте виртуальное окружение:
   ```bash
   poetry shell
   ```

---

## 💻 Использование

### Запуск веб-интерфейса Streamlit
Для запуска интерактивной панели выполните команду:
```bash
poetry run streamlit run src/streamlit_app.py
```

После этого приложение откроется в вашем браузере по адресу `http://localhost:8501`.
