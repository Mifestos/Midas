# Midas

Интерактивное веб-приложение для анализа, прогнозирования и оптимизации инвестиционного портфеля. Система обучает модели Prophet на исторических котировках, строит прогноз стоимости активов и рассчитывает оптимальное распределение весов портфеля для максимизации доходности или минимизации рисков.

## Зачем и для кого этот проект

Проект задумывался как инструмент для частного инвестора, который хочет принимать решения на основе данных, а не интуиции. Вместо ручного сбора котировок, построения графиков и расчёта весов в Excel, система берёт на себя весь цикл: от загрузки исторических цен до визуализации прогноза и готовой структуры портфеля в веб-интерфейсе.

### Как это работает на верхнем уровне:

1. **Данные:** загрузка исторических цен акций из CSV-файла `data/portfolio_prices.csv`.
2. **Прогнозирование:** обучение модели Prophet по каждому тикеру и расчёт ожидаемой доходности.
3. **Оптимизация:** передача прогнозов в математическое ядро для расчёта весов активов.
4. **Визуализация:** интерактивная панель Streamlit с таблицами результатов и круговыми диаграммами Plotly, экспорт графиков прогнозов в PNG.

## Архитектура и технические решения

### 1. Модульный слой прогнозирования

Логика прогнозирования вынесена в отдельный модуль `forecasting.py`. Модель Prophet обучается на исторических данных по каждому тикеру, выделяет долгосрочный тренд и сезонность, после чего возвращает прогноз стоимости на заданный горизонт. Такой подход позволяет изолировать ML-логику от интерфейса и алгоритмов оптимизации.

**Важно с точки зрения архитектуры:** слой прогнозирования не зависит от Streamlit и оптимизатора. Его можно вызывать из скрипта, из панели или из будущего API без изменений в коде.

### 2. Математическое ядро оптимизации

Оптимизация весов вынесена в модуль `portfolio_optimisation.py`. На основе прогнозной доходности рассчитывается рекомендуемое распределение долей акций в портфеле. Расчёт опирается на ожидаемую доходность активов и позволяет выбрать между стратегией максимизации доходности и минимизации рисков.

**Разделение ответственности:** оптимизатор получает на вход только прогнозы и параметры, а возвращает веса. Это упрощает тестирование математики независимо от UI и источника данных.

### 3. Визуализация и интерактивный интерфейс

Веб-интерфейс построен на Streamlit (`streamlit_app.py`). Результаты расчётов отображаются в виде таблиц и круговых диаграмм Plotly, что позволяет наглядно оценить структуру портфеля. Построение графиков вынесено в отдельный модуль `plots.py`, а конфигурация проекта — в `settings.py`.

**Практическая деталь:** графики прогнозов автоматически сохраняются в PNG, что позволяет использовать отчёты вне веб-интерфейса.

## Локальное развертывание

Для запуска проекта достаточно установленных Python 3.12 и Poetry.

### 1. Подготовка окружения

```bash
git clone https://github.com/Mifestos/Midas.git
cd Midas
```
### 2. Установка зависимостей

```bash
poetry install
```
### 3. Активация виртуального окружения
```bash
poetry shell
```
### 4. Запуск веб-интерфейса
``` bash
poetry run streamlit run src/streamlit_app.py
```
Адреса запущенных сервисов

Компонент	URL / Порт
Веб-интерфейс Streamlit	http://localhost:8501
Файл с историческими данными	data/portfolio_prices.csv

# Инженерные заметки (FAQ для отладки при разработке)
Prophet долго обучается на большом числе тикеров: обучение выполняется последовательно по каждому тикеру. Для ускорения итераций в разработке можно сократить список тикеров или горизонт прогноза в settings.py.

Графики не сохраняются: проверьте права на запись в директорию, куда plots.py сохраняет PNG-файлы, и путь в конфигурации.

Streamlit не видит изменения в модулях: при правках в forecasting.py или portfolio_optimisation.py перезапустите приложение, так как Streamlit кэширует импортированные модули.

Обновление зависимостей: проект завязан на Poetry. После правки pyproject.toml обновите lock-файл командой poetry lock.

Данные не подхватываются: убедитесь, что portfolio_prices.csv лежит в data/ и содержит ожидаемые колонки с датами и тикерами.

Экспорт: полноценные отчёты в PDF помимо PNG-графиков.

Безопасность: слой авторизации при развитии проекта в многопользовательский сервис.
