# Midas

Интерактивное веб-приложение для анализа, прогнозирования и оптимизации инвестиционного портфеля. Система загружает исторические котировки, обучает модели Prophet для прогноза стоимости активов, рассчитывает оптимальное распределение весов и визуализирует результат в Streamlit с интерактивными диаграммами Plotly.

---

## Зачем и для кого этот проект

Проект задумывался как инструмент, который автоматизирует рутину частного инвестора. Вместо ручного сбора данных, построения графиков и расчёта весов в Excel, система берёт на себя весь цикл: от загрузки исторических цен до выдачи готовой структуры портфеля с визуализацией долей и сохранением отчёта.

### Как это работает на верхнем уровне:

1. **Загрузка данных:** Исторические цены акций из CSV-файла или внешнего источника.
2. **Прогнозирование:** Обучение моделей Prophet на исторических данных для предсказания стоимости тикеров (например, `AMZN`).
3. **Оптимизация:** Расчёт рекомендуемых долей акций в портфеле на основе ожидаемой доходности.
4. **Визуализация:** Интерактивный интерфейс Streamlit с таблицами результатов и круговыми диаграммами Plotly.

## Архитектура и технические решения

### 1. Модульная структура

Логика разделена по модулям, каждый из которых отвечает за свою задачу:

- **`forecasting.py`** — прогнозирование цен на основе Prophet.
- **`portfolio_optimisation.py`** — алгоритмы расчёта оптимальных весов активов.
- **`plots.py`** — построение графиков прогнозов и диаграмм долей.
- **`settings.py`** — конфигурация и настройки проекта.
- **`main.py`** — основная точка входа.
- **`streamlit_app.py`** — веб-интерфейс Streamlit.

**Важно с точки зрения архитектуры:** Такое разделение позволяет менять модель прогнозирования или алгоритм оптимизации, не затрагивая интерфейс и визуализацию. Конфигурация вынесена в отдельный модуль, а не разбросана по коду.

### 2. Прогнозирование через Prophet

Модели Prophet обучаются на исторических данных по каждому тикеру. Prophet хорошо работает с временными рядами, учитывает тренды и сезонность, а результат прогноза сохраняется в виде графика PNG для отчёта.

### 3. Интерактивный интерфейс на Streamlit

Веб-интерфейс позволяет загрузить данные, запустить прогноз и оптимизацию, а затем посмотреть результаты в виде таблиц и круговых диаграмм Plotly. Результаты можно сохранить — графики прогнозов генерируются автоматически в формате PNG.
